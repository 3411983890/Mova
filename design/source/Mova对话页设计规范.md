> 基线：2026-11-10 的「主页 → 对话」实现（`source/styles.css` 的 `.conversation` / `.act` / `.trace-*` 段、`source/src/features/chat/*`、`source/thinking-block.jsx`）。
> 参考图：[chat-top-reference.png](assets/chat-top-reference.png)（默认折叠态与顶部安全区）、[chat-reference.png](assets/chat-reference.png)（一条回复跑完全部展示能力）、[chat-markdown-reference.png](assets/chat-markdown-reference.png)（正文的表格 / 引用 / 代码块）。
> 数值均为当前代码的实测值；与本文冲突的旧实现，按第 12 节清单逐项收敛。颜色 token 尚未全部落地，第 8 节给出目标名。

## 1. 适用范围与结构

1. **一个消息列，一套执行过程**：主页聊天（ChatMova / CodeMova）与 Bot 会话共用消息列、执行过程与正文排版；差异只在输入框与侧栏（见设置页/输入框规范）。
2. **三层结构**：用户消息 → 助手回复（可选「模拟回复」标签）→ 执行过程（思考 / 搜索 / 命令 / 工具 / 图片）+ 正文。
3. **执行过程可折叠，正文永远可见**：过程用于复盘，正文用于阅读；折叠不能把结论一起藏起来。
4. **只用文字表达悬停**：可折叠标题、来源行、分组头的悬停**只改变文字颜色，不加底色**（第 9 节）。

## 2. 页面骨架与安全区

```
┌ main-panel ────────────────────────────────────────────────┐
│ chat-header（h 46，绝对定位，含标题与操作）                  │
│ chat-fade（h 96，自上而下渐隐，遮住滚动到头部的内容）        │
│ ┌ conversation（width = --content-column，居中）──────────┐ │
│ │ padding-top 104px ← 安全区：渐隐 96 + 8                  │ │
│ │                        [用户消息气泡]（右对齐）           │ │
│ │ 模拟回复                                                  │ │
│ │ ▾ 思考与操作（分组头）                                     │ │
│ │    ▾ 思考 · 摘要                                          │ │
│ │    AnySearch · 查询词   来源 ●●●                          │ │
│ │    ▾ 运行命令 · 标题（终端卡片）                            │ │
│ │    ▸ 写入文件 · 路径（工具行）                              │ │
│ │    ▾ 读取图片 · 路径（缩略图卡片）                          │ │
│ │ 正文（Markdown）                                          │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
| --- | --- |
| 内容列 | `--content-column` = `min(718px, 100% - 48px)`，`margin: 0 auto` |
| 消息间距 | `gap: var(--sp-5)` = **24px** |
| **顶部安全区** | `padding-top: 104px` = 渐隐 96px + 8px 安全距。**首条消息的顶边必须落在渐隐之下**，否则会被渐变压暗、看起来被遮住 |
| 底部留白 | `padding-bottom: 16px`（输入区自身另有外边距） |
| 滚动条 | 内容列隐藏滚动条（`scrollbar-width: none`），靠触控板/滚轮 |
| 聊天头 | `height: 46px`，`padding: 0 12px 0 22px`，标题 15px/600 `#eceeec`，操作区右对齐 |
| 渐隐 | `chat-fade` 高 96px，`linear-gradient(180deg, canvas 0, canvas 50px, rgba(24,24,24,.86) 64%, transparent 100%)`，`pointer-events: none` |

**安全区规则**：任何新增的顶部悬浮元素（工具栏、吸顶提示）都必须算进 `padding-top`；不允许让首条消息压在渐隐或悬浮层下面。

## 3. 消息流

| 项目 | 用户消息 | 助手回复 |
| --- | --- | --- |
| 对齐 | `align-self: flex-end`（右） | 左，占满内容列 |
| 最大宽度 | `80%` | 100% |
| 内边距 | `10px 14px` | 0（正文自己控制） |
| 圆角 | `15px` | — |
| 背景 | `#2f2f2f` | 无 |
| 字号/行高 | 14px / 1.6 | 14px / 1.7 |
| 换行 | `white-space: pre-wrap` + `overflow-wrap: anywhere` | 同左 |

- 用户消息只承载纯文本（图片消息显示「已发送图片」占位），不加头像、不加时间戳。
- 长串无空格文本（路径、URL）必须能断行；不允许撑出内容列。

## 4. 助手回复外壳

| 元素 | 规格 |
| --- | --- |
| `模拟回复` 标签 | `font-size: 12px; color: var(--muted); line-height: 1.5`；只有 `source === 'mock'` 时显示 |
| 状态行 | 同标签字号；`role="status"`；文案：正在生成… / 生成完毕 / 已停止生成 / 上次生成已中断 / 回复生成失败… |
| 重试按钮 | 仅 `error / stopped / interrupted` 出现；边框 `1px #ffffff24`、圆角 6、`padding 4px 10px`、12px |
| 容器 | `display: grid; gap: 8px; grid-template-columns: minmax(0, 1fr)`（**必须**，否则宽表格会把整条回复撑出内容列） |
| 正文块 | `.turn` / `.answer` 都要 `min-width: 0` |

### 4.1 消息操作行（悬停出现）

每条消息下方都有一条操作行。**助手回复的图标常驻**，只有时间 `opacity: 0 → 1` 在指针靠近操作行（或键盘聚焦、展开「⋯」）时出现；**用户消息整行**（时间 + 复制 + 重写）在鼠标进入这一条消息（`.user-turn`）时淡入；时间在左侧，与图标间距 10px。离开即隐藏，不占用正文视觉。

| 角色 | 操作（从左到右） |
| --- | --- |
| 用户消息（右对齐） | **时间** → 复制 → 重写 |
| 助手回复（左对齐） | 复制 → 重新生成 → 回退 → 记忆 → 更多「⋯」 → **时间** |
| 助手回复已停止/中断/失败 | 只保留 **重新生成 + 时间** |

- 图标 **17px**（与执行过程的 13px 图标视觉等重），命中区 **24×24**、圆角 6、间距 2px，整行 `translateX(-3px)` 让图标与正文左缘对齐；默认色 `#8a8a8a`，悬停**只把图标提亮到 `#d5d5d5`**（不加底色，与执行过程的信息行一致）；焦点环 `2px #5b9bf0`。记忆图标与「参考了 N 条记忆」共用同一个 Brain 图标。
- 时间格式 `星期X HH:MM`（**13px / 500 / `#9a9a9a`**），与最后一个图标间距 **9px**，用户消息在左、助手回复在右。
- **「⋯」展开动效**：点击后 ⋯ 宽度收为 0 并淡出（160ms），分支与分享从右侧滑入同一行（`max-width 0 → 48px` + `translateX(-4px) → 0`，200ms），时间随行宽自然右移；再次点击 ⋯ 收起。
- 展开后分支/分享可用键盘 Tab 到达；收起时设 `tabIndex=-1`，不进入焦点顺序。
- 复制：`navigator.clipboard.writeText`，成功/失败都走右下角 toast；回退、记忆、分支、分享在原型中为占位反馈（toast）。

## 5. 执行过程（activity）

### 5.1 分组头 `.act-head`

- 13px / 500，颜色 `#969696`，hover `#cacaca`（**只变色**）；`padding: 2px 0`，`align-self: flex-start`。
- 右侧 chevron 14px，颜色 `#838383`，展开时旋转 180°（180ms）。
- 分组内容 `.act-items`：`gap: 5px`；单行 `line-height: 22px`，图标 14×14，行间距 8。

### 5.2 行内基础行（工具行 / 搜索行）

| 项目 | 值 |
| --- | --- |
| 行高 | 22px（`min-height: 22px`） |
| 文字 | 13px / 500，`label #9a9a9a`，hover `#cacaca` |
| 行尾 meta | 12px `#737373`，`margin-left: auto`，`padding-left: 12px` |
| 图标 | 14×14，颜色 `#8c8c8c` |

可点击的行（来源行）用 `cursor: pointer` + `transition: color .15s ease`；不可点击的纯信息行不加指针与悬停。

### 5.3 思考 `.trace-head` + 展开正文

| 项目 | 值 |
| --- | --- |
| 标题行 | `min-height: 22px`，`padding: 0 8px 0 0`，圆角 7，13px / 500，`line-height: 22px` |
| 标题文字 | 13px / 500 `#a1a1a1`；hover `#cacaca` |
| 摘要 | `#929292`，单行省略；与标题之间用 `·`（`#717171`）分隔 |
| 前置图标 | 14×14 `#8c8c8c`；hover / 展开时原子图标淡出、chevron 淡入（150ms） |
| 展开正文 | `padding: 2px 0 4px 22px`，段落 13px / 450 / 1.65，颜色 `#9d9d9d`，段间距 6px |
| 行内代码 | `padding: 1px 6px`、圆角 5、底 `#2d2d2d`、字 `#d3d3d3`、等宽 12px |

- 摘要 = 第一段的前 100 字（去反引号），展开后完整段落按 `\n\n` 分段。
- 思考块默认收起；**展开动画**：容器 `height` 从 0 到实测高度 + 内容 `translateY(-22px→0)` + 逐段 `blur→清晰`，展开 500ms / 收起 420ms，`prefers-reduced-motion` 时直接切换。

### 5.4 运行命令 `.cmd-card`

| 区域 | 规格 |
| --- | --- |
| 卡片 | 边框 `1px #2b2b2b`、圆角 12、底 `#1a1a1a`、`overflow: hidden`；外层 `padding: 4px 0` |
| 顶栏区 | `padding: 11px 16px 12px 14px`、底 `#1d1d1d` |
| 状态点 | 7px 圆，`#3795f5` + `box-shadow: 0 0 6px rgba(55,149,245,.45)` |
| 工作目录 | 等宽 12.5px / 600，`#d9d9d9` |
| 复制按钮 | 12.5px、`#9c9c9c`；hover 文字 `#e9e9e9` + 底 `rgba(255,255,255,.05)`（这里允许底色，它是按钮不是行） |
| 命令行 | 等宽 12.5px / 1.65，`grid: 14px 1fr`；`$` 提示 `#808080`（不可选中），命令 `#e5e5e5` |
| 输出区 | `padding: 10px 16px 11px 30px`，`border-top: 1px solid #272727`，底 `#171717`，输出文字 `#d3d3d3` |

### 5.5 读取图片 `.img-read-card`

- 外层 `padding: 6px 0 6px 22px`；卡片宽 `286px`、圆角 10、边框 `1px #323232`、底 `#161616`、阴影 `0 8px 24px rgba(0,0,0,.35)`。
- 缩略图 `width: 100%`；展开时 `translateY(-28 → 0)` + `scale(.96 → 1)` + `blur → 清晰`（480/400ms）。

### 5.6 来源 `.source-*`

- 行内：`来源` 按钮（高 22px）+ 站点图标（16px，间距 18.5px）+ chevron；hover 只变文字色。
- 展开：网站图标从行内依次「飞」到最左侧（x=0），下方逐行展开标题 + URL（行高 26px，文字缩进 24px），540/460ms。
- 站点图标内置 reddit / linkedin / github / figma / notion / x；其它站点用 `window.movaDesktop.siteIcon` 取 favicon，取不到时用地球图标。

### 5.7 记忆使用行「参考了 N 条记忆 · 查看」

用于回答「它为什么记得我」：当后端在模型请求开始时返回 `usedIds`，前端在**助手正文之后**追加一行记忆参考。

- 位置：正文之后的独立活动分组，分组头写「参考的记忆」；行内左侧 `参考了 3 条记忆`，紧跟 `查看` 触发按钮（与搜索来源的 `来源` 完全同一位置、同一尺寸）。
- **动效与搜索来源完全一致**：收起时是一行（图标 + 文案 + `查看⌄`）；点开后每条记忆的小图标从右侧依次剥离、飞到最左侧（×0），同时下方按行高 44px 逐行「展开 + 去模糊 + 淡入」（540ms 展开 / 460ms 收起），图标飞行轨迹带 5.5px 弧线。
- 每行内容（**只读**，不提供行内操作）：

| 位置 | 内容 |
| --- | --- |
| 第一行 | 记忆正文，单行省略 |
| 第二行 | `来源：<会话标题>` + 更新时间；无来源显示「手动添加」；停用时追加红色「已停用」 |

- 想修改记忆请去「设置 → 记忆与存储 → 记忆库」：对话里只解释「它为什么记得」，不在这里提供跳转/停用/编辑按钮，避免在阅读路径上堆动作。
- 行高固定 44px（与展开高度计算一致），最多展示 12 条；更多时只显示前 12 条并提示去「记忆与存储」查看。

### 5.8 问答卡片（AI 提问时接管输入栏）

模型在回复末尾主动提问时，**底部输入栏整块换成问答卡片**；作答或跳过后输入栏恢复。卡片与「内联审批栏」同一套表面语言，两者不会同时出现（提问期间审批栏收起）。

```
┌ 问答卡片 1px #343434 / 圆角 12 / 底 #1d1d1d ─────────────────┐
│▌ [AI 提问] 接下来先做哪一块？                                 │
│▌ 选一项我就直接开工；也可以自己写一句。                        │
│  ┌ ○ 问答卡片    AI 提问时接管底部输入栏的这块面板 ┐          │
│  └ ○ 记忆与存储  继续打磨设置页的状态行与分组      ┘          │
│  Enter 提交 · Shift + Enter 换行        [跳过] [提交]        │
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 规格 |
| --- | --- |
| 卡片 | 宽 = 内容列；`padding: 12px 14px 12px 16px`、边框 `1px #343434`、圆角 **12**、底 `#1d1d1d`、阴影 `0 10px 26px #00000040`（与 `.approval-bar` 完全一致） |
| 语义竖条 | 左侧 3px `#3795f5`，`inset: 10px auto 10px 0`，圆角 `0 3px 3px 0` |
| 头部 | `AI 提问` 胶囊（11px、`#3f4a5c` 描边 / `#9dc2f5` 字）+ 题干 13px / 600 `#ededed`；说明 12px `#9d9d9d`、`max-width: 64ch` |
| 选项行 | `padding: 7px 10px`、行间 6px、边框 `1px #333`、圆角 9、底 `#191919`；hover 边 `#575757` + 底 `#262626`；选中 边 `#2d4c74` + 底 `#1e2c3d` |
| 标记 | 14px；单选圆点 / 多选圆角 4 方块；选中填充 `#3795f5`，多选带白色勾 |
| 选项文案 | 标题 12.5px / 500 `#e5e5e5`，副标题 11.5px `#949494`，两行左对齐 |
| 自由输入 | 边框 `1px #333`、圆角 8、底 `#171717`、12.5px；最小高 40、最大 112 |
| 动作区 | 右对齐、间距 8px；`跳过` 为中性按钮（高 30、底 `#262626`、边 `#3d3d3d`），`提交` 为主按钮（`#2f6bd8` 实底白字）；禁用退回 `#222222` 底 + `#6f6f6f` 字。左侧提示 11.5px `#8f8f8f`（窄屏隐藏） |
| 高度 | `max-height: min(46vh, 420px)`；选项区内部滚动，动作区始终可见 |

**交互规则**

| 场景 | 规则 |
| --- | --- |
| 单选 | 点一下先显示选中态，**160ms 后直接作为回答发出**（少一次点击） |
| 多选 | 可勾选多项，需点「提交」；选中项按「、」拼接成一句回答 |
| 简答（无选项） | 卡片只有输入框 + `提交`，空内容时禁用 |
| 自定义回答 | 末行「自定义回答」展开输入框，此时走「提交」，可与多选项一起提交 |
| 跳过 | 卡片收起、输入栏恢复，不写入任何消息，只给一条 toast |
| 作答 | 回答文本作为**用户消息**发出，随后正常进入下一轮回复 |
| 键盘 | 出现即聚焦第一项；↑/↓ 在选项间移动；`Enter` 提交；`Shift + Enter` 换行；`Esc` = 跳过 |
| 会话切换 | 提问只属于发起它的那条会话；切走自动收起，切回来仍在（未回答时） |
| 并发 | 同一时刻只有一个提问；提问期间输入栏与审批栏都收起 |

## 7. 事件协议（后端对接用）

一条回复 = 一串 `ReplyEvent`（`source/src/services/mova-client.ts`），按到达顺序渲染，相邻的非文本事件合并成一个「思考与操作」分组：

| 事件 | 字段 | 渲染 |
| --- | --- | --- |
| `text` | `id`、`text` | 正文；同 id 的多次到达会拼接（流式） |
| `thinking` | `id`、`round`、`text` | 思考块；`round` 用于和历史轮次对应 |
| `search` | `id`、`query`、`status`、`detail?`、`sources?` | 搜索行 + 来源；`running → done/error` 同 id 合并 |
| `command` | `id`、`title?`、`cwd?`、`commands[]`、`output[]`、`status?` | 终端卡片 |
| `tool` | `id`、`icon?`、`label`、`meta?` | 工具行（写文件 / 读文件等） |
| `memory-used` | `id`、`memories[]`（`id`/`text`/`kind`/`updatedAt`/`conversationTitle`/`conversationId`/`messageId`/`status`） | 记忆使用行；出现在正文之后，自成一组 |
| `image` | `id`、`name`、`src?` | 读取图片卡片 |
| `ask` | `id`、`question`、`detail?`、`options?`（`value`/`label`/`description`）、`multi?`、`allowCustom?`、`placeholder?` | 底部问答卡片（5.8）；**不进入执行过程**，等回复 `done` 后接管输入栏 |

规则：
- 同 `type + id` 的事件视为同一条目的增量（`mergeReplyEvent`），文本/思考拼接，搜索/命令/工具合并。
- 正文的 id 以「轮次:」开头（如 `2:answer`），用于把 `round` 的思考写回历史。
- 一轮结束后，正文 = 所有 `text` 事件以 `\n\n` 拼接。
- 状态：`streaming / done / stopped / interrupted / error`；`stopped` 时未完成的 `search` 会落成「搜索已停止」。

## 9. 状态、悬停与动效

| 交互 | 规则 |
| --- | --- |
| 可折叠标题（思考 / 运行命令 / 读取图片） | hover **只改文字颜色**：`#a1a1a1 → #cacaca`；摘要、路径同步变色；**不加背景** |
| 分组头 | 同上：`#969696 → #cacaca`，不加背景 |
| 搜索 / 来源行 | 同上：`#9a9a9a → #cacaca`，不加背景 |
| 卡片内按钮（复制） | 允许底色：hover `rgba(255,255,255,.05)` + 文字提亮 |
| 焦点 | 全局 `2px #5b9bf0`，`outline-offset: 3px`；行内可折叠标题也要可见 |
| 展开 / 收起 | `height + translateY + blur` 组合曲线，展开 500ms、收起 420ms；`prefers-reduced-motion` 全部关闭 |
| 流式状态 | `正在思考 / 正在搜索 / 正在回复` 带扫光动画；结束后改为 `生成完毕`（视觉隐藏，仅留给读屏） |
| 停止 | 输入框的停止按钮中止流；未完成搜索落成「搜索已停止」，保留已显示内容，出现「重新生成」 |

> **为什么只变色**：执行过程的标题是「信息行」，底色会让整片区域看起来像被选中或可拖拽；同一列里搜索行已经确立「文字变色 = 可点」的约定，思考与运行命令必须一致。

### 9.1 输入栏权限选择（请求批准 / 替我审批 / 完全访问权限）

| 元素 | 规则 |
| --- | --- |
| 菜单面板 | 底 `#2e2e2e`，圆角 16px，内边距 6px；vendor 的浅色 utility 底一律压平，避免浅底叠浅字 |
| 行悬停 / 高亮 | 底 `#3a3a3a`；标题 `#f2f2f2`，副标题 `#b9b9b9`，图标 `#d0d0d0`（只提亮，不改变层级） |
| 当前选中 | 行首左侧勾号 + 滑动底块 `#343434`（静止状态可见，不依赖悬停） |
| 「完全访问权限」 | 危险项：**悬停 / 高亮 / 选中时整行转橙**——标题与图标 `#f0a05a`、副标题 `#d99a63`、底 `#3b2e25`；未交互时与其他行一致，仅靠勾号与底块表示当前项。橙色行不参与「提亮为白色」的规则 |

**窄宽度收起**：触发器所在列一旦放不下整段文字（`label.scrollWidth > label.clientWidth + 1`，即出现省略号），弃用文字、收成一个 **32×32 圆形图标**（权限图标 14px 居中，隐藏 chevron）。判断由 `composer.js` 的 `bindApprovalTriggerFit` 测量并写入 `[data-mova-fit="icon"]`，宽度恢复后自动还原文字；`title` 与视觉隐藏的 label 分别保证鼠标与读屏仍能读到当前权限。

> 为什么量文字而不是用容器查询：三档权限文字长度不同（4 / 4 / 6 字），且工具栏左右两侧的按钮数量会变；只有「这段文字有没有被截断」才是真正的触发条件。

## 11. 无障碍

1. 可折叠标题用 `<button aria-expanded>`；分组头同样；展开内容在收起时设 `aria-hidden`。
2. 状态变化用 `role="status"`（`aria-live="polite"`）；错误用 `role="alert"`。
3. 来源展开后是真实链接（`<a href target="_blank" rel="noopener noreferrer">`），可用 Tab 到达。
4. 消息锚点：`#message-…` 与 `${id}-assistant` 可被 URL hash 与 `mova:reveal-message` 事件定位，定位后把焦点移到该消息。
5. 文字对比度：正文、思考、链接均 ≥ 4.5:1；`meta #737373` 目前 3.74:1，需提升到 `#828282` 以上（待确认）。
6. 动效尊重 `prefers-reduced-motion`。

## 12. 演示脚本与验收清单

**演示脚本**：输入「你好」（正则 `^你好[!！。.~～\s]*$`）会触发一条覆盖全部组件的模拟回复，顺序为：思考 ×2 → 搜索（3 来源）→ 运行命令 → 写文件工具行 → 读文件工具行 → 读取图片 → 正文第一段 → 第二轮思考 → 第二轮搜索（2 来源）→ 正文续写（表格 / 引用 / 代码块 / 任务列表 / 链接）。它只用于检查 UI，不调用模型、不写数据。

新增或修改对话 UI 时逐条确认：

- [ ] 首条消息顶边在渐隐之下（安全区 ≥ 104px），没有被压暗或裁切。
- [ ] 消息列宽 = `--content-column`；宽表格/长代码只在自己的容器里滚动。
- [ ] 用户气泡右对齐、最大 80%、圆角 15、底 `#2f2f2f`。
- [ ] 执行过程默认收起；展开动画平滑，收起后不留空白。
- [ ] 所有信息行（思考 / 运行命令 / 读取图片 / 搜索 / 来源 / 分组头）hover 只变文字色，没有底色。
- [ ] 卡片内按钮（复制）hover 允许底色，且焦点可见。
- [ ] 正文 Markdown：标题层级、表格、引用、代码块复制、任务列表、链接都正常。
- [ ] 流式三态（正在思考 / 正在搜索 / 正在回复）与停止、错误、重新生成都能触发。
- [ ] AI 提问时底部换成问答卡片：单选题点即发、多选与简答需「提交」、跳过后输入栏恢复。
- [ ] 点右上角「⋯」时三个点原位隐去、Token 用量卡片形变展开；Esc / 点外部 / 关闭按钮都能收回并复位三个点。
