# Mova 浏览器前端（HTML 网页版）独立备份

备份时间：2026-11-10 19:50（本机时间）
来源：`Mova` 项目的浏览器前端（不含 Electron 桌面外壳与后台）

> 说明：主项目此时仍在被其他进程持续修改。本副本是上一步同步完成那一刻的完整快照（56 个前端文件逐一校验与主项目一致），之后主项目的新改动不会自动进入这里。

这是一份**独立的 HTML 网页版前端**：不依赖主程序、不需要安装依赖、不需要启动任何服务，双击即可在浏览器中查看和操作。

## 1. 直接打开（查看效果）

双击本目录的 `index.html`。

- 地址栏显示 `file:///.../design/index.html`，说明确实是纯网页离线打开。
- 界面为模拟模式：聊天回复是本地示例文本，不调用任何模型，也不会发送数据到外部。
- 桌面版专属能力（真实模型、密钥、本地会话存储、窗口按钮）在网页版按原有逻辑降级为不可用/示例状态。

已验证（Chromium 内核无头浏览器，文件协议）：

- 页面标题、样式、图标字体、小球与输入框正常渲染；
- 设置页、MovaBot、社区三个面板可正常打开；
- 发送消息能得到模拟回复；
- 全部浏览器异常与失败请求：0。

## 2. 修改网页（两种方式）

### 方式 A：只改样式或文案（最快）

直接用编辑器修改 `index.html` 与 `styles.css` / `keyline-icons.css` / `project-dialog.css` / `app.css`，刷新浏览器即可看到效果。只改这些文件不需要 Node.js。

### 方式 B：改界面逻辑（推荐，源码级）

界面逻辑集中在 `source/`。改完重新打包，才会更新根目录的 `index.html` 和 `app.js`：

```powershell
cd design

npm.cmd install --ignore-scripts   # 仅首次/换机；本机已带好 node_modules
npm.cmd run dev                    # 开发预览（热更新）→ http://127.0.0.1:4174/
npm.cmd run build                  # 重新生成可双击的 index.html + app.js
npm.cmd run typecheck              # TypeScript 检查
```

> 本机 PowerShell 禁止运行 `npm.ps1` 时，请使用 `npm.cmd`，无需改系统执行策略。
> 端口 4173 属于主项目，本副本固定用 4174（被占用时直接报错，不会抢端口）。

## 4. 与主程序的隔离方式

1. **实体副本**：源码、素材、依赖都是复制品，没有任何符号链接或对父目录 `node_modules` 的引用。
2. **输出不外溢**：构建根目录是 `design/source`，输出目录是 `design`，缓存写入 `design/node_modules/.vite`；不会写主项目的 `dist/`、源码或配置。
3. **不启动桌面端**：不含 Electron 主进程、模型代理、密钥存储；网页版没有 `window.movaDesktop`，界面走原有的“仅浏览器”分支。
4. **数据不串台**：浏览器存储键由 `mova.*` 改为 `mova-design.*`，网页版不会覆盖主界面的工作区与模型偏好。
5. **端口独立**：开发 4174、预览 4175，与主项目 4173 分开。
6. **可整体搬走**：整个 `design` 文件夹复制到任意位置都能双击打开；改源码只需 `npm.cmd install`。

备份后主项目仍可继续开发，两边互不覆盖。这是一份快照，不会自动同步回主程序。

## 5. 内置浏览器（右侧分屏）

点击主页或聊天页右上角的面板图标，会在右侧打开内置浏览器分屏；再次点击图标或使用三点菜单中的“关闭分屏”即可收起。

- 顶部只保留一条浏览器栏：后退、前进、刷新、网址栏，右侧只有三点菜单；栏高 43px，控件按比例缩到 2/3。
- 工具栏在顶部单独占一行高度，网页从工具栏下沿开始渲染，页面顶部不会被栏遮住；向下滚动时工具栏收起，网页顺势上移占满。
- 浏览器栏浮层不再覆盖网页，滚动时不会盖住正文。
- 三点菜单提供“在新标签页打开”“复制网址”“刷新”“关闭分屏”。
- 拖动分屏左边缘可调整宽度，双击恢复默认宽度；网址和宽度会记住上次选择。
- 往右拖到小于最小宽度后再拖 36px，整个分屏自动收回，和侧栏的收起手势一致。
- 往左拖到对话区极限时先停住（边缘高亮），松开鼠标后再往左拖一次才收起对话区，避免误触。
- 对话区收起后完全隐藏（不再保留窄边），点左上角图标第一下只恢复对话，不会顺带展开左侧列表；双击分屏边缘同样恢复。
- 打开分屏或窗口变窄时，空间不够会先自动收起左侧二级菜单（项目/聊天列表），保留中间对话区；分屏始终并排，不会盖住对话。
- 对话区变窄时输入栏逐级精简：先隐藏「请求批准」，最后只剩加号、模型与发送。
- 内嵌页面隐藏右侧与下侧滚动条：同源时注入样式并按宽度等比缩放，跨域时把 iframe 放大一圈再裁切，把滚动条推到可视区外。
- 左侧项目/聊天面板展开时，如果放不下对话区，右侧分屏会自动收回，把空间让给左侧；若对话区当时被分屏挤掉，同样先收回分屏、把对话还回来。
- 同源页面可读取滚动位置，滚动收起/出现完整生效；跨域页面受浏览器安全限制，无法读取其滚动位置，可通过顶部细把手唤回；焦点在 Mova 界面时也可按 `Ctrl+L`。
- 聊天列表行尾常驻“x分钟 / x小时 / x天”，悬停时时间淡出、归档按钮滑入；左右外边距已收窄，滚动条不再占位。时间列按内容自适应，标题因此能多显示几个字。
- 设置页左侧导航与聊天列表共用同一套外边距（容器左右 8px），条目内边距同聊天标题一致，文字起点对齐。

## 7. 通讯录

活动栏第三个图标打开通讯录（整页视图，和社区一样不显示项目侧栏与输入框）。

- 左列：全部 Bot，支持搜索、按标签 / 星标筛选、按最近使用或名称排序，星标 Bot 置顶分组；上下方向键在行间移动。
- 列表标题右侧只有两个图标：放大镜（和主页二级菜单右上角的搜索同款）与圆形加号（和「消息」页右上角的加号同款）。搜索框不再常驻，点放大镜才展开，再点一次或按 Esc 收起并清空，焦点回到放大镜；展开后输入框仍带清除按钮。
- 右列：所选 Bot 的个人主页——大头像（悬停、点击有表情回应）、名字与标签、个人介绍（可就地编辑）、创建时间与最近使用时间（辅助信息）；右下角是「星标」（纯图标）与「发消息」。
- 使用记录：累计消息 / 对话 / Token / 活跃天数四个数字，加近 14 天每日消息柱状图（悬停看当天数值）。统计为本地示例，在私聊里发消息会实时累加。
- 模型与工具：点模型弹出「选择模型」浮层（和输入框里的模型菜单同一套样式，当前项加粗并打勾）；思考强度是与输入栏同款的 canvas 滑杆（流动的星云渐变、果冻手柄、拖动时加速，档位越高色相越偏紫），换到不支持思考的模型会整条置灰并清空；六个工具逐个开关，并显示已启用数量。
- 创建 Bot：除了形象、名字、标签、描述，还可以选模型（可思考的模型会多出「思考强度」三档）与免打扰。
- 所在群聊（点击直达该群聊）。
- 免打扰：立即生效，「消息」列表里同步显示静音标记。
- 删除 Bot：确认框逐条列出对 Bot 本身、私聊记录（具体条数）、群聊（具体群名）的影响；内置的 MovaBot 不可删除。
- 数据在 `source/bot-directory.js`，界面在 `source/src/features/contacts/`；「消息」页与通讯录共用同一份 Bot 资料。

## 8. Bot 对话与群聊

「消息」页的 Bot 对话另有一套头部交互：

- 右上角只保留「…」，不再提供内置浏览器的展开按钮（Bot 对话没有浏览器分屏）。
- 点「…」：
  - 单聊弹出 Bot 信息浮层——头像、名字、标签、个人介绍、所用模型与思考强度、免打扰开关，以及「查看完整主页」直达通讯录。
  - 群聊弹出群聊浮层——上半部分是成员头像宫格，下半部分是群名（可就地改名）、工作位置、免打扰，以及「删除群聊」。
- 「删除群聊」走规范里的确认弹窗：说明会删除群聊与其中的消息，并明确指出成员 Bot、私聊和其它群聊不受影响；确认后才真正删除。
- 工作位置点开是独立弹窗（项目 / 此电脑文件夹 / 不设置），不再是下拉菜单；新建群聊里也复用同一个弹窗。
- 两个浮层都复用 Token 用量卡片的形变动效：从「…」原位展开成卡片、关闭时收回按钮，内容延迟淡入。
- Bot 列表右上角的加号改成「新建群聊」：群名、成员多选（至少 2 个 Bot，选中时小球放彩带）、工作位置；创建后直接进入该群聊，并在列表顶部出现。
- 群聊在列表里的头像由成员头像叠成，不加底色。

## 9. 已知边界

- 第三方组件（如 LeiBox 输入框、图标库）沿用各自许可证，部分含商用条款，详见 `THIRD_PARTY_NOTICES.md` 与 `source/vendor/*/LICENSE*`。
