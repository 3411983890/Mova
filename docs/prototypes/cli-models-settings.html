额度调度

所有切换都发生在发请求之前：额度不足的账号不会被选中，也不会把请求发出去再失败。

额度用尽时自动切换账号

命中额度上限时自动改用下一个有额度的账号，并在时间线里标注「已切换」。

优先账号

轮换始终从这里开始；被标记额度用尽的账号会临时跳过。

剩余额度低于 10% 时提醒

在下一次发消息前提示一次，不打断正在进行的任务。

额度刷新间隔

空闲时按此间隔读取额度；发送前一定重新校验一次。

会话模型

模型清单来自账号目录，未授权或已下线的模型不会出现在这里。

思考强度

两侧都支持；实际取值会不会被接受，由所选模型决定。

图片输入

当前账号目录报告支持图片；关闭后附件只保留文件名。

运行方式

ChatGPT 由 Mova 直接发请求；Gemini 交给本机 CLI，Mova 只保留渲染与审批。

ChatGPT 通道

Responses 接口，令牌由本机加密保存，过期前自动续期。

Gemini 执行器

后台 CLI（ACP）：思考、计划、工具与审批请求都会回到 Mova 的时间线与审批条。

CLI 路径

找不到时会在 PATH 中搜索 agy；修改后立即用于下一次会话。

C:\Users\…\AppData\Local\antigravity\agy.exe
凭据存储

refresh token 由系统钥匙串加密；应用内不写入明文，日志与错误信息不含令牌。

系统钥匙串（DPAPI）
订阅额度仅限本人在本设备使用

这些额度来自你个人账号的套餐，不是 API 计费额度。不要共享账号或把额度转给其他人使用。
